| 2026-11-12 | **PSD import with automatic slots**: a template can be imported from a PSD, read in the browser (the file is never uploaded). With the placeholder layers hidden the background is Photoshop's flattened image, exact; otherwise it is redrawn from the layers without layer effects, and the importer says so. Settles #19 | Developer decision. Settles the font half of #17 (a platform template library stays open) | Developer decision.
